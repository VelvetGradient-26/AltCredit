HOW TO USE
----------
* Run from the repo root:  /Users/deepak/Desktop/AltCredit
* The code is already written, so this is release pacing: run each block at the
  time shown (T+ = hours:minutes after kickoff). Git stamps each commit with the
  time you actually run it - do NOT backdate with GIT_AUTHOR_DATE.
* Two tracks are listed. If two teammates split the work, each runs one track in
  parallel. If one person does everything, follow the MERGED TIMELINE at the bottom.
* The backend track and the frontend track touch different folders, so they never
  conflict with each other. Within a track, run the commits IN ORDER: each one only
  depends on files from earlier commits.
* Before commit #1 of the whole session, unstage the renames/deletes that are
  already staged in the index (this keeps every file on disk):

      git reset

* Sanity check before each commit (optional, 2 seconds):

      git diff --cached --stat

* `git add -A <path>` is used wherever a file was deleted or moved out of
  machine_learning/, so the deletion is recorded together with the new file.
* Never `git add .` - the repo also has unrelated untracked files in Artifacts/.
